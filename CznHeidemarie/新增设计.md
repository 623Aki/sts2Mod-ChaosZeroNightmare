## 一、STS2 的战斗风格与特色（源码调研结论）

调研对象：`SlayTheSpire2_source/`（反编译源码，权威于一切教程）。

### 1.1 骨架仍是尖塔，但节奏更快

| 项目    | STS2 实际情况                      | 源码依据                                                                |
| ----- | ------------------------------ | ------------------------------------------------------------------- |
| 每回合能量 | **3**（调试角色除外）                  | `CharacterModel.MaxEnergy => 3`                                     |
| 第二资源  | **星能 Stars**：能量不足时 1 能量 = 2 星  | `PlayerCombatState.Stars`；`Hook.ShouldPayExcessEnergyCostWithStars` |
| 格挡清空  | 回合结束清空，但**第 1 回合不清空**（STS2 新增） | `Creature.cs:690-694`，`TurnNumber == 1` 跳过 `ClearBlock()`           |
| 出牌上限  | 无 STS1 的"每回合限制"，靠能量自然限制        | —                                                                   |

> **设计含义**：STS2 允许玩家在一回合内滚更大的雪球（星能补费、首回合保格挡），
> 因此"单卡高上限 + 需要 setup"的设计比 STS1 更安全 —— 这正好契合本角色
> 「攒连接 → 一波打出」的节奏。

### 1.2 STS2 相对 STS1 的新增机制

| 新机制                       | 说明                                                      | 源码位置                                                             |
| ------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------- |
| **Sly（狡黠）**               | 被弃掉时**自动免费打出**                                          | `CardKeyword.Sly`、`AutoPlayType.SlyDiscard`、`CardCmd.cs:188-204` |
| **Eternal（永恒）**           | 该卡**无法被移除 / 转化 / 删除**                                   | `CardModel.IsRemovable => !Keywords.Contains(Eternal)`           |
| **星能 Stars**              | 见上                                                      | `PlayerCombatState.cs:190-209`                                   |
| **免费打出类 Power**           | `FreeAttackPower` / `FreeSkillPower` / `FreePowerPower` | `src/Core/Models/Powers/`                                        |
| **充能球 OrbQueue**          | STS2 全新系统                                               | `PlayerCombatState.OrbQueue`、`CharacterModel.BaseOrbSlotCount`   |
| **宠物 / Osty**             | 召唤物，可作为目标                                               | `TargetType.Osty`、`PlayerCmd.AddPet<T>()`                        |
| **附魔 Enchantment**        | 单卡附魔，可改费用 / 伤害                                          | `EnchantmentModel`、`CardModel.Enchantment`                       |
| **Quest 卡 / Ancient 稀有度** | 新卡类与新稀有度                                                | `CardType.Quest`、`CardRarity.Ancient`                            |
| **多人联机**                  | Hook 普遍带 `Player owner` 参数                              | `TargetType.AnyPlayer / AnyAlly / AllAllies`                     |

**完整关键字枚举**（`CardKeyword.cs`）：
`None, Exhaust, Ethereal, Innate, Unplayable, Retain, Sly, Eternal`

### 1.3 官方在「格挡 / 过牌 / 丢弃」三个维度的标准答案

这是第 1 轮设计的直接参照系。

**格挡**

```csharp
GainBlock(Creature creature, decimal amount, ValueProp props, CardPlay? cardPlay, bool fast = false)
```

**过牌**

```csharp
// src/Core/Commands/CardPileCmd.cs
Draw(PlayerChoiceContext choiceContext, decimal count, Player player, bool fromHandDraw = false)
```

官方模板：

| 卡                 | 费用 | 效果                  | 定位                             |
| ----------------- | -- | ------------------- | ------------------------------ |
| `Backflip.cs`     | 1  | 5 格挡 + 抽 2          | **格挡与过牌合一张**（本轮「极光护壁 / 守望」的参照） |
| `Acrobatics.cs`   | 1  | 抽 3 弃 1             | **过牌带弃牌代价**（本轮「落刃」的参照）         |
| `BattleTrance.cs` | 0  | 抽 3 + `NoDrawPower` | 纯过牌上限                          |
| `Adrenaline.cs`   | 0  | +1 能量 + 抽 2，消耗      | **能量与过牌合一张**（本轮「破晓」的参照）        |

**丢弃**

```csharp
// src/Core/Commands/CardCmd.cs  ← 注意在 CardCmd，不在 CardPileCmd
Discard(PlayerChoiceContext choiceContext, CardModel card)                       // 单张
Discard(PlayerChoiceContext choiceContext, IEnumerable<CardModel> cards)         // 批量
DiscardAndDraw(PlayerChoiceContext ctx, IEnumerable<CardModel> toDiscard, int toDraw)
```

> ⚠️ 源码注释明确警告：**批量弃牌不要循环调用单张版**，否则 `Sly` 的自动打出时机会错。
