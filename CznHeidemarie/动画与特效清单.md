### 4.1 立绘（`StaticPortrait`）

`破军(ux)全屏演出用的三张官方插画骨架`（**纯角色，无背景图**），三张都按 `intro → loop` 播放
（由 `metadata/czn_portrait_animation = "intro,loop"` 声明，运行时执行）。

| 项 | 值 |
| - | - |
| 场景 | `scenes/screens/char_select/heidemarie_static_portrait_bg.tscn` |
| 背景 | **无**（底图交回游戏选人界面自己的背景；图片资源仍在 `images/character_select/heidemarie_select_bg_30093_1.png`） |
| 素材 | `CznHeidemarie/animations/effects/heidemarie_30093_ux_illust_{1,2,3}.{skel,atlas,png}` + 各自 `_skel_data.tres` |
| 皮肤 / 动画 | 单一皮肤 `default`；每张 2 段动画 `intro` / `loop` |
| 层序（后→前） | `illust_3`（z=1）→ `illust_2`（z=3）→ `illust_1`（z=4） |
| 标定（1920×1080 设计坐标） | 三层**共用** `position (1186, 542)`、`scale 0.54`（居中偏右，让开描述文本） |

> 三张骨架的骨骼树完全相同，是同一张 cut-in 的三层切片，因此**必须共用同一套变换**，
> 否则三层会互相错位。
> 骨架原点在内容中部（pivot 处），**不在包围盒左下角**。
> 屏幕映射关系为 `屏幕 y = Y − scale × y`（Spine y 向上）。要更大就继续等比调大 `scale`，
> `X` 按每 0.1 scale 约 +85 跟进（保持左缘位置）。
> 背景层 `illust_3` 的石柱 / 花会直接落在游戏自己的背景上；不需要时把该节点 `visible` 置 false。
> 这三张骨架**只被选人界面使用**，`heidemarie_ux.json` 里不含它们。

### 4.4 布局与运行时的三个要点

1. **设计坐标**：立绘类变体里 SpineSprite 的 `position` / `scale` 都按 **1920×1080** 标注，
   运行时按 `cover` 比例映射到实际视口（`ratio = max(w/1920, h/1080)`，中心对齐）。
2. **皮肤与动画必须在运行时设**：`.tscn` 里的 `preview_skin` / `preview_animation`
   只对编辑器预览生效。本工程用两组 meta 声明意图，由运行时执行（带就绪重试）：
   `metadata/czn_portrait_skin`（皮肤名）、`metadata/czn_portrait_animation`（逗号分隔，末段循环）。
3. **大厅那一档走另一套布局**（1580×720 视口 + 各层居中 + `StartLobbyLoop` 循环启动重试），
   与立绘两档互不影响；循环启动后用 `czn_heidemarie_lobby_loop_started` 标记防止重播。

### 7.2 触发与生命周期

```
Hook.ModifyAttackHitCount（Registration/HeidemarieCombatPresentationPatch.cs）
   └─ 卡牌是 HeidemarieLiberatedAurora ? → route "ug"（触发器 GAttack）
      卡牌是 HeidemarieFinalEcho     ? → route "ux"（触发器 XAttack）
          └─ 本地 Heidemarie 玩家 & 战斗未结束 &
             EffectiveEffectsEnabled && ShowCardPlayPresentation
              └─ CombatAttackFullScreenPresentationPolicy.Allows（致死预判）
                  ├─ 不通过 → HeidemarieMoveEffectsRuntime.PlayFallback 补播常规特效
                  └─ 通过 → 取施法者 Spine 锚点（CombatCreatureSpineResolver）
                      └─ 实例化舞台场景，挂到 NCombatRoom
                          └─ configure(route, anchor, ownerPosition)
                              └─ get_runtime_contract() → 校验 duration / hit / actorRelease 单调
                                  └─ 收掉出牌特写立绘（HeidemarieBattleReadyRuntime.Cleanup）
                                      └─ 隐藏本体，start_stage()
                                          ├─ presentation_started → 记录开演时刻
                                          ├─ takeover_reached   → 黑幕压下来的时刻（本体此刻才隐藏）
                                          ├─ hit_reached        → 放行命中闸门（攻击在这里才结算伤害）
                                          ├─ actors_restored    → 归还本体 + SetAnimationTrigger("Idle")
                                          ├─ stage_finished      → 收尾 + 放行收尾闸门
                                          └─ resources_finished  → 释放节点
```

> 挂载点选 `Hook.ModifyAttackHitCount`：它在 `AttackCommand.Execute` 里紧跟
> `Hook.BeforeAttack` 调用，是「攻击指令已组好、骨架动作还没播、伤害还没结算」的时刻，
> 只有拿到 `AttackCommand` 才能做「可击杀敌人才播」的致死预判。

### 7.2.1 伤害时机对表（命中闸门 / 收尾闸门）

原生 `AttackCommand.Execute` 的节奏是「触发施法者动作 → 等 `waitTime` → 结算伤害」，
而 `waitTime` 只服务于原生骨架动作，与演出时间轴无关，伤害总是抢在动画前面落地。
对齐办法与两个参考 mod（Nine 的 `TryWaitForHit` / Tiphera 的 `TryGetCoveredBodyWait`）一致：

| 环节 | 补丁                               | 行为                                                                   |
| -- | -------------------------------- | -------------------------------------------------------------------- |
| 命中 | `CreatureCmd.TriggerAnim` Prefix | 触发器是 `XAttack` / `GAttack` 且演出在跑时，把「等 `waitTime`」换成「等 `hit_reached`」 |
| 收尾 | `Hook.AfterAttack` Postfix       | 把 `Hook.AfterAttack` 的返回值接到舞台收尾上，整段演出播完才结束这次出牌                       |

两道闸门都由 `Phase` 里的 `TaskCompletionSource` 承载，**取消 / 降级 / 看门狗超时都会在
`End()` 里无条件放行**，不会把出牌吊死；演出不存在或已降级时闸门不生效，走原生等待。

| 写    | `SetCombatPresentationMode(Custom)` + `SetCardPlayPresentationEnabled(...)`，**持久化** |
| 可用条件 | `EffectiveEffectsEnabled`（通用「战斗特效」总开关关掉时按钮不显示）                                     |

> 与设置面板里「你的全屏角色演出」是**同一个值** —— 战斗里点按钮等于改设置，反之亦然。
> 关掉后终结技改播第八节登记的常规特效，不会变成「只有一段身体动作」。

## 八、单体技能特效

卡牌打出时，在**施法者 / 目标自己身上**叠加一批特效骨架。架构见
**`参考mod动画实现清单.md` 第八节**；本节记录本工程的实际接线。

### 8.1 四层文件

| 层   | 文件                                                   | 说明                                                |
| --- | ---------------------------------------------------- | ------------------------------------------------- |
| 数据  | `CznHeidemarie/effects/heidemarie_moves.json`        | 键 = 卡牌 C# 类型名；`owner` / `target` 两组图层，共 **35 键 / 210 条** |
| 合成器 | `CznHeidemarie/effects/heidemarie_effect_stage.gd`   | 自己解析时间轴、建 SpineSprite、走毫秒时钟                       |
| 场景  | `CznHeidemarie/effects/heidemarie_effect_stage.tscn` | 根节点 `Node2D`                                      |
| 接入  | `Integration/HeidemarieMoveEffectsRuntime.cs`        | 触发、锚点解析、舞台回收、预加载                                  |

> 210 条图层共引用 **58 组唯一骨架**（骨架跨招式复用，见 5.8 的注）。
> `z` 已由 `tools/extract_cinematic_plan.py --command moves-z` 从 `.cfx` 回填真值；
> `start_ms` / `end_ms` / `clip` 是按**身体动画相位**人工对齐的，被 C# 侧依赖，不要乱改。
> 合成器对 `z` 做保序压缩到 `[-4000, 4000]`（`set_z_index` 只接受该区间，越界会被直接拒绝）。

### 8.2 与全屏演出的三点不同

|     | 全屏演出（第七节）                                                  | 单体特效（本节）                                             |
| --- | ---------------------------------------------------------- | ---------------------------------------------------- |
| 根节点 | `CanvasLayer`（`layer=4090`）                                | `Node2D`                                             |
| 挂在哪 | `NCombatRoom` 下                                            | **施法者 / 目标自己的骨架节点下**                                 |
| 坐标  | 1280×720 设计画布 + cover 缩放，需换算                               | **不需要换算** —— 直接继承单位的位移、朝向与缩放                         |
| 画面  | 黑幕 + 镜头抖动 + 隐藏本体                                           | 无，纯叠加                                                |
| 触发  | `Hook.ModifyAttackHitCount`（需 `AttackCommand` 做致死预判）        | `CardPlayEnqueuingEvent`（**带 target**，正是官方预留的出牌演出时机） |
| 开关  | `EffectiveEffectsEnabled` **且** `ShowCardPlayPresentation` | 只需 `EffectiveEffectsEnabled`                         |

### 8.3 终结技的双套特效切换

「解放极光」与「绝响」在时间轴里**同样登记了常规特效**，但只在全屏演出**不接管**时才播：

| 场景                                        | 播放内容                                                         |
| ----------------------------------------- | ------------------------------------------------------------ |
| 全屏演出开 + 致死预判通过                            | 全屏演出（第七节），单体特效让位                                             |
| 全屏演出开 + 致死预判不通过                           | 由 `HeidemarieCinematicRuntime` 调 `HeidemarieMoveEffectsRuntime.PlayFallback` 补播常规特效 |
| 全屏演出关（`ShowCardPlayPresentation = false`） | 常规特效（由 `WillTakeOver` 判定为不接管，走正常出牌流程）                         |

> 判定点：`HeidemarieCinematicRuntime.WillTakeOver(card)` = `HasCinematicRoute(card) && IsEnabled()`。
> 单体特效的触发（`CardPlayEnqueuingEvent`）早于演出的致死预判，所以只能先按「演出开不开」让位，
> 再由演出侧在不接管时回补一次。
>
> 目标展开：单体牌用事件带来的目标；「绝响」是 `TargetType.AllEnemies`（目标为 `null`），
> 由 `ResolveTargets` 展开成**每一个存活敌人各建一个舞台**。
