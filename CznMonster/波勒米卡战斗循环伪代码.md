# 波勒米卡战斗循环（伪代码）

```text
// 变量
turn          = 1          // 当前回合
hpPct         = 100%       // 波勒米卡当前生命百分比
brood         = 0          // 孵化仪式，0..3
livingAdds    = 0          // 场上存活召唤物数量（不含 Boss）
summonedOnce  = false      // 是否已经召唤过第一波
state         = 军团召集    // 当前行动/分支状态

while (战斗未结束)
{
    // ── 开场：第一回合固定军团召集 ─────────────────────────
    if (state == 军团召集)
    {
        召唤第一波（2 个军团兵蚁 + 1 个军团盾蚁）
        summonedOnce = true
        brood = min(3, brood + 1)
        state = P1分支
    }

    // ── P1：前半场主循环 ──────────────────────────────────
    else if (state == P1分支)
    {
        if (summonedOnce == true && livingAdds == 0)
        {
            首领突袭
            brood = min(3, brood + 1)
            state = P3分支
        }
        else if (brood >= 3)
        {
            全军换防
            state = P1分支
        }
        else if (hpPct < 50%)
        {
            甲壳壁垒
            state = 精锐孵化        // P4 只停 1 回合
        }
        else
        {
            军团冲锋
            brood = min(3, brood + 1)
            state = P1分支
        }
    }

    // ── P3：小怪死光后的单体阶段 ──────────────────────────
    else if (state == P3分支)
    {
        if (brood >= 3)
        {
            全军换防
            state = P1分支
        }
        else if (livingAdds >= 2)
        {
            军团召集
            brood = min(3, brood + 1)
            state = P1分支
        }
        else if (hpPct < 50%)
        {
            甲壳壁垒
            state = 精锐孵化
        }
        else
        {
            首领突袭
            brood = min(3, brood + 1)
            state = P3分支
        }
    }

    // ── P4：甲壳壁垒，只停 1 回合 ─────────────────────────
    else if (state == 甲壳壁垒)
    {
        处决全部召唤物
        brood = 0
        获得格挡
        state = 精锐孵化
    }

    // ── P5：后半场主循环 ──────────────────────────────────
    else if (state == 精锐孵化)
    {
        召唤第二波（岩壳虫 + 翼壳虫 + 壳虫）
        brood = min(3, brood + 1)
        state = P5分支
    }
    else if (state == P5分支)
    {
        if (livingAdds == 0)
        {
            终局突刺
            brood = min(3, brood + 1)
            state = P7分支
        }
        else if (brood >= 3)
        {
            精锐换防
            state = P5分支
        }
        else
        {
            垂死冲锋
            brood = min(3, brood + 1)
            state = P5分支
        }
    }

    // ── P7：精英死光后的终局循环 ──────────────────────────
    else if (state == P7分支)
    {
        if (brood >= 3)
        {
            精锐换防
            state = P5分支
        }
        else if (livingAdds >= 2)
        {
            垂死冲锋
            brood = min(3, brood + 1)
            state = P5分支
        }
        else
        {
            终局突刺
            brood = min(3, brood + 1)
            state = P7分支
        }
    }

    // ── 换防动作 ─────────────────────────────────────────
    else if (state == 全军换防)
    {
        处决全部召唤物
        Boss 力量 +2 × 被处决召唤物数量
        brood = 0
        召唤第一波
        state = P1分支
    }
    else if (state == 精锐换防)
    {
        处决全部召唤物
        Boss 力量 +2 × 被处决召唤物数量
        brood = 0
        召唤第二波
        state = P5分支
    }

    turn++
    hpPct = 波勒米卡当前生命 / 最大生命
    livingAdds = 场上存活召唤物数量
    wait(行动动画结束)
}
```

## 行动说明

| 行动 | 效果 |
|---|---|
| 军团召集 | 召唤第一波：2 个军团兵蚁 + 1 个军团盾蚁；仪式 +1 |
| 军团冲锋 | 攻击；全体己方 +1 力量；仪式 +1 |
| 首领突袭 | 重击；仪式 +1 |
| 全军换防 | 处决全部召唤物；Boss 力量 +2 × 被处决召唤物数量；仪式清零；重召第一波 |
| 甲壳壁垒 | 处决全部召唤物；仪式清零；获得格挡；下一回合进入 P5 |
| 精锐孵化 | 召唤第二波：岩壳虫 + 翼壳虫 + 壳虫；仪式 +1 |
| 精锐换防 | 处决全部召唤物；Boss 力量 +2 × 被处决召唤物数量；仪式清零；重召第二波 |
| 垂死冲锋 | 攻击；全体己方 +1 力量；仪式 +1 |
| 终局突刺 | 重击；仪式 +1 |

## 关键判定

- `brood >= 3`：下一次行动优先执行换防。
- `livingAdds == 0`：P1 会打「首领突袭」，P5 会打「终局突刺」。
- `livingAdds >= 2`：P3 会重新「军团召集」，P7 会打「垂死冲锋」。
- `hpPct < 50%`：P1 / P3 会进入「甲壳壁垒」。
- `summonedOnce && livingAdds == 0`：P1 的最优先分支，先打「首领突袭」再进 P3。

## 被召唤物战斗循环

所有召唤物共用外层循环：

```text
while (自己存活 && 战斗未结束)
{
    if (登场当回合)
    {
        不行动                 // 原生 SpawnedThisTurn
        wait(回合结束)
        continue
    }

    next = 自身 RandomBranch 掷下一个行动

    if (next == 攻击系行动)
    {
        执行对应行动
    }
    else if (next == 防御系行动)
    {
        执行对应行动
    }
    else if (next == 增益/减益系行动)
    {
        执行对应行动
    }

    wait(行动动画结束)
}
```

下面按怪物拆分；**循环结构完全相同的会合并写**。

### 第一波召唤物

#### 军团兵蚁

```text
state = 战吼突刺

while (自己存活)
{
    if (state == 战吼突刺)
    {
        攻击目标
        全体己方 +1 力量
        state = 兵蚁分支
    }
    else if (state == 撕咬)
    {
        攻击目标
        目标 1 层易伤
        state = 兵蚁分支
    }
    else if (state == 兵蚁分支)
    {
        state = RandomBranch(
            战吼突刺: weight 0.60, 最多连续 2 次,
            撕咬:     weight 0.40, 不能连续
        )
    }
}
```

#### 军团盾蚁

```text
state = 撞角

while (自己存活)
{
    if (state == 撞角)
    {
        攻击目标
        state = 盾蚁分支
    }
    else if (state == 掩护)
    {
        攻击目标
        全体己方加格挡
        state = 盾蚁分支
    }
    else if (state == 盾蚁分支)
    {
        state = RandomBranch(
            撞角: weight 0.40, 最多连续 1 次,
            掩护: weight 0.60, 最多连续 2 次
        )
    }
}
```

### 第二波召唤物

#### 岩壳虫

```text
state = 碎岩重击

while (自己存活)
{
    if (state == 碎岩重击)
    {
        攻击目标
        目标 2 层脆弱
        state = 岩壳虫分支
    }
    else if (state == 岩壳硬化)
    {
        播硬化动画
        自己 +4 力量
        弃置每个玩家的全部手牌
        state = 岩壳虫分支
    }
    else if (state == 岩壳防御)
    {
        攻击目标
        自己获得格挡
        state = 岩壳虫分支
    }
    else if (state == 岩壳虫分支)
    {
        state = RandomBranch(
            碎岩重击: weight 0.55, 可重复, 无冷却,
            岩壳硬化: weight 0.20, 可重复, 冷却 3 回合,
            岩壳防御: weight 0.25, 可重复, 冷却 2 回合
        )
    }
}
```

#### 壳虫 / 翼壳虫

两者战斗循环完全相同，合并写；只有“攻击后挂的减益”不同：

```text
state = 攻击分支

while (自己存活)
{
    if (state == 攻击分支)
    {
        攻击目标

        if (自己是翼壳虫)
        {
            目标 2 层易伤
        }
        else
        {
            目标 2 层虚弱
        }

        state = 壳虫系分支
    }
    else if (state == 防御分支)
    {
        攻击目标
        自己获得格挡
        state = 壳虫系分支
    }
    else if (state == 壳虫系分支)
    {
        state = RandomBranch(
            攻击分支: weight 0.65, 可重复,
            防御分支: weight 0.35, 不能连续
        )
    }
}
```

## 被召唤物行动说明

| 怪物 | 行动 | 效果 |
|---|---|---|
| 军团兵蚁 | 战吼突刺 | 攻击；全体己方 +1 力量 |
| 军团兵蚁 | 撕咬 | 攻击；目标 1 层易伤 |
| 军团盾蚁 | 撞角 | 攻击 |
| 军团盾蚁 | 掩护 | 低伤害攻击；全体己方加格挡 |
| 岩壳虫 | 碎岩重击 | 攻击；目标 2 层脆弱 |
| 岩壳虫 | 岩壳硬化 | 自己 +4 力量；弃置每个玩家全部手牌；3 回合冷却 |
| 岩壳虫 | 岩壳防御 | 低伤害攻击；自己获得格挡；2 回合冷却 |
| 壳虫 | 甲壳撕咬 | 攻击；目标 2 层虚弱 |
| 翼壳虫 | 翼击 | 攻击；目标 2 层易伤 |
| 壳虫 / 翼壳虫 | 甲壳防御 / 翼壳防御 | 低伤害攻击；自己获得格挡 |

## 被召唤物关键判定

- 所有召唤物登场当回合不行动，从下一回合开始进入上面的循环。
- 召唤物只在自己的 `RandomBranch` 里循环，不参与 Boss 的 `brood` 仪式计数。
- 壳虫与翼壳虫除减益类型不同外，分支权重、连击限制、冷却规则完全一致。
- 岩壳虫的「岩壳硬化」有 3 回合冷却，「岩壳防御」有 2 回合冷却。
