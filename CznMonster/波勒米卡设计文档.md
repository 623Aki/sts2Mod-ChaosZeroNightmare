## 1. 机制设计

### 1.1 Boss 状态机（9 个 MoveState + 4 个条件分支）

开场行动 = `BROOD_CALL`（军团召集）。分支**先加先判**（`ConditionalBranchState` 按插入顺序取第一个满足的谓词）：

```
BROOD_CALL / LEGION_CHARGE / REBROOD ─→ P1_BRANCH（前半场主循环）
   ① _summonedOnce && LivingAdds==0 → SOLO_STRIKE
   ② _brood >= 3                    → REBROOD（换防）
   ③ HpPercent < 0.5                → SHELL（进后半场）
   ④ 否则                           → LEGION_CHARGE

SOLO_STRIKE ─→ P3_BRANCH（小怪死光后的单体期）
   ① _brood >= 3        → REBROOD
   ② LivingAdds >= 2    → BROOD_CALL
   ③ HpPercent < 0.5    → SHELL
   ④ 否则               → SOLO_STRIKE

SHELL ─→ ELITE_HATCH          // 甲壳壁垒只停 1 回合（后半场过渡，不合回分支）

ELITE_HATCH / SECOND_WIND / ELITE_REBROOD ─→ P5_BRANCH（后半场主循环）
   ① LivingAdds == 0    → FINAL_STRIKE
   ② _brood >= 3        → ELITE_REBROOD
   ③ 否则               → SECOND_WIND_CHARGE

FINAL_STRIKE ─→ P7_BRANCH（精英死光后的终局循环）
   ① _brood >= 3        → ELITE_REBROOD
   ② LivingAdds >= 2    → SECOND_WIND_CHARGE
   ③ 否则               → FINAL_STRIKE
```

- `LivingAdds` = 己方存活召唤物数（不含自己）；`HpPercent` = `Creature.GetHpPercentRemaining()`。
- 仪式计数在 `Polemica` 内部字段 `_brood`（0..3，封顶判 `PolemicaBroodPower.Threshold`），`PolemicaBroodPower` 只做显示与查询，两边同步。

### 1.3 召唤物（基类 `PolemicaAddMonster` + 4 个子类）

基类统一：`ShouldShowInCompendium=false`（不进原生章节图鉴，走专属区块）；登场即挂原生 `MinionPower`（不阻止胜利、不掉奖励）；进场当回合不行动由原生 `SpawnedThisTurn` 处理；`DamageSfxType=Armor`；登场动画 = 初始 AnimState，音效在 `AfterAddedToRoom` 补播（`EntranceSfxClip`）。

| 岩壳虫 `1001019` | `POLEMICA_ROCK_SHELL_INSECT` | 102（108） | **碎岩重击**（55%，可重复）：9 伤害 + 玩家 2 层虚弱；**岩壳硬化**（20%，冷却 3）：自身 +4 力量 + 每名玩家抽牌堆中稀有度最高的 1 张牌移入弃牌堆（带预览）；**岩壳防御**（25%，冷却 2）：9 伤害 + 自身 15 格挡 |

升华「致命敌人」各伤害 +1（精英伤害类 +2）、HP 松「强敌」+2/+6；数值 getter 均先取升华值再乘章节系数。

岩壳硬化取牌优先级（与原版 ThievingHopper 同手法）：稀有 Ancient/Rare → Uncommon → Common → 全部（兜底），随机流用怪物侧 `RunRng.CombatCardGeneration`；抽牌堆空或目标无归属玩家则跳过。

### 1.4 被处决表现（基类可覆写成员）

处决是「一拍」：Boss `Fatal` 动画 + 采样与全部召唤物反应动画**并行起手**（`Task.WhenAll`），播完 `CreatureCmd.Kill(adds, force:true)` 一次性击杀——不逐个播。

| 怪物 | 反应动画（等待） | 处决采样 | 死亡采样 |
| --- | --- | --- | --- |
| 不屈的库勒提 / 装甲库勒提 | `Surprise`→`normal_surprise`（0.55s，骨架无 fatal） | 无 | `skill2`（复用撕咬采样） |
| 岩壳虫 / 翼壳虫 / 壳虫 | `Fatal`→`normal_fatal`（1.5s） | `fatal` | 无（处决时已播,不重复） |

`ExecuteAdds` 内**不手动 `CombatState.RemoveCreature`**：`CreatureCmd.Kill` 已按原生流程异步殉死亡动画并释放节点，提前摘除会让死亡贴图与 `HoverTips` 访问空 CombatState（NRE 刷屏）。

### 1.5 召唤与槽位

- `FindFreeSlot` 只把「**存活**且槽名相同」视为占用（不用 `Encounter.GetNextSlot`：它只比对槽名，刚死未清理的尸体会挡槽）；槽满则该次召唤跳过。
- 槽位顺序 = 遭遇 Slots 顺序（`add1 → add2 → boss → add3`，实占召唤位为前三个按可达顺序补空）。
- 第一波 `SummonWave1` = 不屈的库勒提 → 装甲库勒提 → 不屈的库勒提；第二波 = 岩壳虫 → 翼壳虫 → 壳虫。

### 1.6 图鉴：专属「CZN 怪物」区块

原生图鉴按「章节 → 遭遇 → AllPossibleMonsters」收集，本 mod 首领只走首领替换、从不进遭遇池，原生流程查无此怪。`CznMonsterBestiaryPatch` 在 `NBestiary.AddEvents` 的位置 Prefix 插入：区块标题复用 `NBestiaryLabelDivider`（键 `CZN_MONSTERS.title`），条目用原生私有 `AddEntries` 添加 `BestiaryEntry.FromMonster(...)`；排序、锁定态、点击信号全部走原实现；仅在 `CznMonstersEnabled` 开启时展示，不改游戏资源。

现行条目（11 条）：

| 遭遇 | 条目 |
| --- | --- |
| 波勒米卡 | 波勒米卡、不屈的库勒提、装甲库勒提、岩壳虫、翼壳虫、壳虫 |
| 塞拉菲翁 | 塞拉菲翁、阿克鲁斯 |
| 阿涅丝 | 阿涅丝、阿涅丝·弗布尔加扎伊特（第二形态，独立展示模型 `AgnesFinal`）、余响碎片 |

**招式按钮是纯演出**：`MonsterModel.GenerateBestiaryMoveList` 的默认实现只探测名为 `die` / `hurt` 的 clip，而 CZN 骨架叫 `normal_death` / `stance1_death` / `normal_hit` —— 默认流程永远不会生成「死亡」按钮；状态型按钮还会让图鉴执行 `PerformMove()`（真跑战斗逻辑，图鉴里是 `NullCombatState`）。因此本 mod 全部怪物 override 该函数，统一交给 `Content/Bestiary/CznBestiaryMoves.cs` 组装：每条按钮只做「播 clip（非死亡动作播完接回待机）+ 播一条采样」，死亡按钮固定在真实死亡 clip 上。

| 怪物 | 死亡 clip | 死亡采样 |
| --- | --- | --- |
| 波勒米卡 / 塞拉菲翁 / 阿克鲁斯 | `normal_death` | `death` |
| 不屈/装甲库勒提 | `normal_death` | `skill2`（复用撕咬采样） |
| 岩壳虫 / 翼壳虫 / 壳虫 | `normal_death` | 无（处决时已播 `fatal`） |
| 阿涅丝（Form A） | `normal_groggy`（骨架无死亡动作） | 无 |
| 阿涅丝·弗布尔加扎伊特 | `stance1_death` | `death` |
| 余响碎片 | `normal_hit`（骨架仅 idle/hit） | 无 |

音效走 `CznMonsterSfx` 的本地 ogg 表；图鉴里没有战斗房间，播放器回退挂到 `NGame` 根上，否则会「只有动画、没有声音」。

### 3.3 音效（`CznMonsterSfx` 占位路径机制）

六个 CZN bank（28 条采样）已全部导出为 ogg 到 `res://CznMonster/audio/sfx/polemica/<怪物 id>/`。`AttackSfx/DeathSfx/HurtSfx` 返回占位事件路径（前缀 `event:/sfx/enemy/enemy_attacks/cznmonster/<entry>/<clip>`），由 `Registration.CznMonsterSfxPatch` 的 `SfxCmd.Play`/`PlayDeath` 前缀补丁解析成本地 ogg 并吞掉原调用（其它怪物零侵入）。战斗开始时按遭遇预热缓存；播放器最多 4 个 `AudioStreamPlayer`，挂 `NCombatRoom` 离房即失效。

| entry | clip → ogg |
| --- | --- |
| POLEMICA | `enter`→normal_enter；`skill1_3/2_3/3/4`→各自 `se_corpsleader_formica_normal_*`；`fatal`→se_1001013_normal_fatal；`death`→se_1001013_normal_death；`hurt`→`se_1001013_groan_1/2/3`（**随机一条**） |

## 5. 本地化

游戏只认 `res://CznMonster/localization/{lang}/<table>.json`；zhs / eng 两套同步，键名由类名转 `SCREAMING_SNAKE`。

```jsonc
// monsters.json（节选结构，键全量已在落盘文件内）
"POLEMICA.name": "波勒米卡",
"POLEMICA.moves.BROOD_CALL.title": "军团召集",
...（9 个 Boss 招式 + 5 只召唤物 name/moves）

// encounters.json
"POLEMICA_BOSS.title": "波勒米卡",
"POLEMICA_BOSS.loss": "[gold]{encounter}[/gold]的军团踏平了{character}的最后一道防线。",

// powers.json
"POLEMICA_BROOD_POWER.title": "孵化仪式",
"POLEMICA_BROOD_POWER.description": "波勒米卡每行动一次，此计数 +1。达到 3 时，它的下一次行动将处决全部召唤物并召唤新的一波。",

// bestiary.json（图鉴区块标题）
"CZN_MONSTERS.title": "CZN 怪物"
```

图鉴招式名键式 = `<entry>.moves.<StateId 去 _MOVE>.title`；换防/护盾三个动作经 `ShouldShowMoveInBestiary` 排除。

## 6. 注册与补丁

| 挂点 | 内容 |

| `MonsterContent.BossEncounters` | `PolemicaBoss` + `SeraphionEncounter`。首领永不进普通池，只走首领替换 |
