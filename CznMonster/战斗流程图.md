## 1. 塞拉菲翁（双怪战：塞拉菲翁 240 HP + 阿克鲁斯 152 HP）

两条命绑在一起：阿克鲁斯活着时塞拉菲翁打不死，必须先处理阿克鲁斯。

```mermaid
flowchart TD
    S0["战斗开始：塞拉菲翁 240 HP ／ 阿克鲁斯 152 HP"] --> B0["塞拉菲翁每拍判定（按序）"]

    B0 --> J1{"刚被救起待复归？"}
    J1 -->|"是"| REV["自身 +45 格挡 ／ 伤害 3×12 ／ 回到前半场循环"]
    J1 -->|"否"| J2{"阿克鲁斯已死？"}
    J2 -->|"是"| FIN["力量 +2 ／ 此后每拍 伤害 4×12（无出口）"]
    J2 -->|"否"| J3{"本阶段已出 2 拍？"}
    J3 -->|"否"| BITE["伤害 2×12 ／ 拍计数 +1"]
    J3 -->|"是"| CYC["伤害 3×10 ／ 拍计数归零"]

    BITE --> B0
    CYC --> B0
    REV --> B0
    FIN --> FIN
```

前半场节奏：伤害 2×12 → 伤害 2×12 → 伤害 3×10 → 再回到伤害 2×12，如此循环。

```mermaid
flowchart TD
    A0["阿克鲁斯每拍判定"] --> A1{"塞拉菲翁处于濒死？"}
    A1 -->|"是"| RES["救援三拍（严格串行，每拍一步）"]
    A1 -->|"否"| A2{"守护拍计数为偶数？"}
    A2 -->|"是"| WARD["全体己方 +22 格挡、力量 +1"]
    A2 -->|"否"| AS["伤害 3×12 ／ 守护拍计数 +1"]

    WARD --> A0
    AS --> A0

    RES --> R1["第 1 拍：伤害 12 ／ 自身 +45 格挡"]
    R1 --> R2["第 2 拍：玩家全体 虚弱 2 ／ 脆弱 2 ／ 力量 -1"]
    R2 --> R3["第 3 拍：濒死的塞拉菲翁回 50% 最大生命并起身"]
    R3 --> A0
```

正常守护节奏：+22 格挡/力量 +1 → 伤害 3×12 → 交替。

```mermaid
flowchart TD
    L0["塞拉菲翁被打到 0 HP（阿克鲁斯存活）"] --> L1["拦在 1 HP ／ 进入濒死：倒地、不可选中、不吃伤害、无意图、清空其余能力"]
    L1 --> L2["阿克鲁斯当场改写为救援第一拍"]
    L2 --> L3["救援三拍：伤害 12 + 自身 45 格挡 → 玩家 虚弱 2 ／ 脆弱 2 ／ 力量 -1 → 回血 50%"]
    L3 --> L4["塞拉菲翁起身：下一拍为 自身 +45 格挡 ／ 伤害 3×12，然后回前半场循环"]
    L4 --> L5["此后照常受伤，可再次濒死（保护不消耗，可反复）"]

    L1 --> K0["此时阿克鲁斯被击杀"]
    K0 --> K1["塞拉菲翁当场真死"]
    L5 --> K2["阿克鲁斯在其他时刻被击杀"]
    K2 --> K3["塞拉菲翁健康 → 力量 +2 后进入 每拍 伤害 4×12 的终局"]
```

## 2. 波勒米卡（第 3 章，450 HP + 3 个召唤位）

核心是「行动 3 次必换防」：处决自己全部召唤物、按处决数量涨力量、重新召唤一批。

```mermaid
flowchart TD
    P0["战斗开始"] --> CALL["召唤第一波 3 只：库勒提·兵 ×2 + 库勒提·盾 ×1（仪式 +1）"]
    CALL --> P1{"前半场·有召唤物时判定（按序）"}

    P1 --> C1{"仪式达到 3？"}
    C1 -->|"是"| REB["处决全部召唤物 ／ 力量 +2×处决数 ／ 仪式清零 ／ 重召第一波 3 只"]
    C1 -->|"否"| C2{"生命低于 50%？"}
    C2 -->|"是"| SHELL["处决全部召唤物 ／ 仪式清零 ／ 自身 +45 格挡"]
    C2 -->|"否"| CHG["伤害 30 ／ 全体己方 力量 +1（仪式 +1）"]

    REB --> P1
    CHG --> P1
    SHELL --> HATCH["下一拍固定：召唤第二波 3 只：岩壳虫 + 翼壳虫 + 壳虫（仪式 +1）"]

    P1 -->|"召唤物全灭"| SOLO["伤害 24（仪式 +1）"]
    SOLO --> P3{"前半场·召唤物全灭时判定"}
    P3 --> D1{"仪式达到 3？"}
    D1 -->|"是"| REB
    D1 -->|"否"| D2{"场上召唤物已达 2 只？"}
    D2 -->|"是"| CALL
    D2 -->|"否"| D3{"生命低于 50%？"}
    D3 -->|"是"| SHELL
    D3 -->|"否"| SOLO
```

## 3. 美梦（第 1 章，640 HP，单体双阶段）

被它打不计时，**打它才计时**：每次受击计数 -1，归零则全部被偷的牌回到手牌，它回满计数并涨力量。

```mermaid
flowchart TD
    M0["战斗开始：持有 梦魇 7 层 ／ 每回合玩家抽牌后偷 1 张手牌"] --> P1{"阶段 1 每拍判定（按序）"}

    P1 --> G1{"计数归零？"}
    G1 -->|"是"| AW["归还全部被偷的牌 ／ 力量 +1 ／ 计数回满 7"]
    G1 -->|"否"| G2{"生命低于 40%？"}
    G2 -->|"是"| NR["进入阶段 2：偷牌量变 2 张 ／ 计数 +10 ／ 伤害 4×14"]
    G2 -->|"否"| RND["随机：伤害 3×14（70%）／ 伤害 2×15 + 玩家 虚弱 2（30%）"]

    AW --> P1
    RND --> P1
    NR --> P2{"阶段 2 每拍判定"}

    P2 --> H1{"计数归零？"}
    H1 -->|"是"| AD["归还全部被偷的牌 ／ 力量 +2 ／ 计数回满 10"]
    H1 -->|"否"| RND2["随机三选一"]
    AD --> P2

    RND2 --> R2A["伤害 3×15 + 玩家 虚弱 2 ／ 脆弱 2（30%）"]
    RND2 --> R2B["伤害 2×15 ／ 自身 力量 +2（40%）"]
    RND2 --> R2C["伤害 4×14（30%）"]
    R2A --> P2
    R2B --> P2
    R2C --> P2
```

受击计数规则：

```
玩家每打出一次命中（多段攻击按段计） → 计数 -1
计数归零 → 全部被偷的牌回手 → 下一拍必定是「回满计数 + 涨力量」
每回合玩家抽牌后 → 随机偷 1 张（阶段 1）／ 2 张（阶段 2）
```

## 4. 阿涅丝（第 3 章，640 HP，单实体双形态）

第一形态按固定 4 拍轮换；生命 <50% 后插一拍变身（判定实际发生在每拍开始，下图按轮末表示），第二形态每轮 3 个随机不重复行动 + 第 4 拍必处决。

```mermaid
flowchart TD
    A0["战斗开始（第一形态，640 HP）"] --> T1["伤害 9×3"]
    T1 --> T2["全体己方 力量 +2"]
    T2 --> T3["伤害 26"]
    T3 --> T4["玩家 虚弱 2 ／ 脆弱 2"]
    T4 --> CHK{"生命低于 50%？"}
    CHK -->|"否"| T1
    CHK -->|"是"| TR["变身（占一拍）：回血 20% 已损失生命 ／ 力量 +3 ／ 召唤 3 只碎片（每只 18 HP）／ 共鸣 3 层"]
    TR --> POOL["进入第二形态（见下图）"]
```

```mermaid
flowchart TD
    POOL["第二形态：每轮 = 3 拍随机不重复 + 第 4 拍必处决"] --> D0{"本轮已出 3 拍？"}
    D0 -->|"否"| DRAW["从未抽过的池中随机抽取"]
    D0 -->|"是"| EXEC["处决"]

    DRAW --> X1["伤害 30"]
    DRAW --> X2["伤害 34"]
    DRAW --> X3["伤害 8×3"]
    DRAW --> X4["玩家 虚弱 2 ／ 脆弱 2 ／ 共鸣 +2"]
    X1 --> POOL
    X2 --> POOL
    X3 --> POOL
    X4 --> POOL

    EXEC --> E1["先杀掉场上全部碎片"]
    E1 --> E2["伤害 9 ×（1 + 共鸣层数 + 2×存活碎片数）"]
    E2 --> E3["重召 3 只碎片 ／ 共鸣重铺 3 层 ／ 拍计数归零"]
    E3 --> POOL
```

处决伤害速查（基础 9）：

| 状况 | 共鸣 | 碎片 | 伤害 |
| --- | --- | --- | --- |
| 碎片一只不清、抽到蓄力拍 | 5 | 3 | 108 |
| 碎片一只不清 | 3 | 3 | 90 |
| 清 1 只、抽到蓄力拍 | 5 | 2 | 90 |
| 清 2 只、抽到蓄力拍 | 5 | 1 | 72 |
| 清 3 只、抽到蓄力拍 | 5 | 0 | 54 |
| 清 3 只 | 3 | 0 | 36 |

> 每清一只碎片 = 少挨 18 点；碎片只有 18 HP，且不会攻击（每拍只空过）。共鸣只增不减、上限 10。

## 5. 四首领共同点速查

| 首领 | 关键节奏 | 破局点 |
| --- | --- | --- |
| 塞拉菲翁 | 前半场每 3 拍一轮（2×12、2×12、3×10）；伴生每拍 +22 格挡或 3×12 | 先杀阿克鲁斯：否则塞拉菲翁打不死，且它会进入每拍 4×12 的终局前先补 45 格挡 |
| 波勒米卡 | 每 3 次行动必换防，换防按处决数给它涨力量 | 别让它靠召唤物堆力量；召唤物全灭也不会停手，只会反复重召 |
| 美梦 | 打它才降计数，计数归零就还牌 + 涨力量 | 多段攻击划算（既打伤害又加速赎回）；阶段 2 偷牌翻倍，要立刻打满 10 次 |
| 阿涅丝 | 第一形态 4 拍固定，第二形态 3 随机 + 1 处决 | 处决前清碎片，每只碎片等于 18 点减伤；碎片只有 18 HP |
