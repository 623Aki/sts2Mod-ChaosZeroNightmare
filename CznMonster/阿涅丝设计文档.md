## 1. 机制

### 1.1 形态与阶段

```
开场 = 集约期（Form A，normal_* 骨架，HP 640）
  ├─ 每拍轮换：连击 → 增益 → 重击 → 压制低语（`_faTurn % 4`）
  └─ 拍首判定：`!_formB && HP < 50%` ⇒ 强制进入「变身·壹」一拍
变身·壹（不占额外回合，就是一拍）
  ① normal_model_transform_to_stance1（2.00s）
  ② 运行时换骨 → agnes_final 骨架（缩放 0.70 / 位偏 (-30,-200) / 意图位 (0,-690)）
  ③ `_formB = true`，`Title` 切到 `AGNES_FINAL.name`
  ④ stance1_model_transform_end（3.67s）
  ⑤ 回复已损失生命的 20%（向下取整）
  ⑥ 召唤余响碎片 ×3
  ⑦ 共鸣铺 3 层 + 力量 +3
绽放期（Form B，stance1_* 骨架，血量延续）
  每轮 = 3 个随机行动（袋抽不重复）+ 第 4 拍必「处决」
  重击·贰 / 斩击 / 压制 / 三连 → 处决 → 重召碎片 ×3 → 共鸣重铺 3 → 拍游标归零
```

- **没有登场空过拍**：初始状态直接挂 Form A 分支，第 1 个玩家回合就有真实意图；登场动画由 Animator 的初始 `AnimState`（`normal_enter`）负责。
- **变身只触发一次**：`fa` 分支的首个谓词是 `!_formB && HP < 50%`，变身完成后不再命中。

### 1.2 行动状态机（`Agnes.GenerateMoveStateMachine`）

| 状态 id | 意图 | 行为 | 游标 |
| --- | --- | --- | --- |
| `AGNES_COMBO_MOVE` | `MultiAttackIntent` 9 × 3（升华 10 × 3） | `normal_attack_play2`，接 `combo` 采样 | `_faTurn++` |
| `AGNES_BUFF_MOVE` | `BuffIntent` | `normal_buff_1`，全体己方（含自身）力量 +2 | `_faTurn++` |
| `AGNES_HEAVY_MOVE` | `SingleAttackIntent` 26（升华 29） | `normal_attack_ready` | `_faTurn++` |
| `AGNES_SUPPRESS_A_MOVE` | `DebuffIntent` | 虚弱 2 + 脆弱 2；Form A 无 debuff 动作，借 `normal_buff_1` 施法定格 | `_faTurn++` |
| `AGNES_TRANSFORM_MOVE` | `SummonIntent` + `BuffIntent` | §1.1 变身七步 | 重置 `_faTurn/_fbTurn` |
| `AGNES_HEAVY_B_MOVE` | `SingleAttackIntent` 30（升华 33） | `stance1_m_attack_01`（2.33s） | `_fbTurn++` |
| `AGNES_TRIPLE_MOVE` | `MultiAttackIntent` 8 × 3（升华 9 × 3） | `stance1_attack_play1` | `_fbTurn++` |
| `AGNES_SUPPRESS_MOVE` | `DebuffIntent` | 虚弱 2 + 脆弱 2 + 共鸣 +2（蓄力拍） | `_fbTurn++` |
| `AGNES_SLASH_MOVE` | `SingleAttackIntent` 34（升华 37） | `stance1_s_attack_01_play`（3.00s） | `_fbTurn++` |
| `AGNES_EXECUTE_MOVE` | `AgnesExecuteIntent`（图标 `intent_death_blow`，委托实时取伤害） | §1.4 | `_fbTurn = 0` |

两个分支节点：

- `AGNES_FA_BRANCH`（`ConditionalBranchState`，先加先判）：变身 → 连击 → 增益 → 重击 → 压制低语。
- `AGNES_FB_POOL_STATE`（`AgnesFormBPoolState : MonsterState`，`ShouldAppearInLogs = false`）：本轮已走 3 拍则返回处决并清袋；否则从 [重击·贰 / 斩击 / 压制 / 三连] 里随机抽一个**未抽过**的，袋空时重填。

> 抽签发生在引擎 `PrepareForNextTurn → RollMove`（一次 RollMove 只调一次 `GetNextState`），因此抽到的招 = 随后显示并执行的招。

### 1.3 共鸣（`AgnesResonancePower`）

- **只增不减**，上限 10；普通攻击既不吃也不消耗。
- 增长源只有两个：变身 / 处决后的**重铺 3**；**蓄力拍（压制）+2**。
- 一阶段不挂共鸣（`AddResonance` 有 `!_formB` 闸），Power 在变身拍才首次出现，作为「新机制登场」的信号。
- 层值写回走 `SetAmount`，与模型内字段 `_resonance` 同步（显示 = 实值）。

### 1.4 处决（`ExecuteMove`）

```
① 先捕获系数：1 + 共鸣层数 + 2 × 场上存活碎片数
② 收割全部碎片（CreatureCmd.Kill(force:true)；不给层、不联动）
③ 倾泻共鸣的一刀：基础 9（升华 10）× 系数，播 stance1_s_attack_01_play（3.00s）
④ 重召碎片 ×3
⑤ 共鸣清零重铺 3，_fbTurn = 0
```

- 系数必须在斩杀**之前**读取（斩杀后场上碎片归零）。
- 三个入参与意图委托同源，玩家看到的数字就是实伤；回合内打碎一只碎片，图标数字当场降一档。

### 1.5 余响碎片（`AgnesEcho`）

- HP 18（升华 21）；`ShouldShowInCompendium = false`；`AfterAddedToRoom` 挂 `MinionPower`。
- 骨架只有 `normal_idle` / `normal_hit` 两条动作（各 8s 时间轴），**没有攻击、没有音频 bank**：
  - 行动 = 「随波哼鸣」空过拍（`HiddenIntent`，不出意图图标）。
  - 死亡触发器落 `normal_hit` 定格；时长由 `Registration/EchoDeathAnimPatch` 压缩
    （`NCreature.GetCurrentAnimationLength / GetCurrentAnimationTimeRemaining` 只对 `AgnesEcho` 封顶 0.5s / 0.25s）。
- 碎片的价值只体现在处决公式里（每只 +2 系数 = 18 点），死亡不产生任何回馈。

### 1.6 死亡

- Form A：骨架无死亡动作 → `Dead` → `normal_groggy` 兜底；**无死亡采样**（`HasDeathSfx = _formB`）。
- Form B：`Dead` → `stance1_death` + `death` 采样。

## 2. 数值

### 2.1 现行数值（2/3 章基准，升华值在括号内）

| 项 | 值 |
| --- | --- |
| Boss HP | 640（672）；`MonsterSettings.CustomBossHp` 只覆盖基础值，仍乘章节系数 |
| 碎片 HP | 18（21）× 3；**不随章节缩放**（必须与处决折算值 18 等价） |
| 连击 | 9（10）× 3 段 = 27（30） |
| 重击 | 26（29） |
| 重击·贰 | 30（33） |
| 三连 | 8（9）× 3 段 = 24（27） |
| 斩击 | 34（37） |
| 处决基础 | 9（10） |
| 增益拍 | 全体己方力量 +2 |
| 压制（Form A / Form B） | 虚弱 2 + 脆弱 2；Form B 额外共鸣 +2 |
| 变身·壹 | 回血 20% 已损失 + 力量 +3 + 召唤 ×3 + 共鸣铺 3 |
| 共鸣 | 上限 10，重铺 3，蓄力 +2 |

### 2.2 章节缩放（`AgnesScaling`）

`ActIndex` 由遭遇生成时写入（读档在 `GenerateMonsters` 按当前 `RunState` 兜底）：

- HP：第 1 章 ×0.40（256）、第 2 章 ×0.62（396）、第 3 章 ×1.0（640）。
  系数按**原生同幕 Boss 血池阶梯**标定（第 1 幕单体 173~262、第 2 幕 321~428、第 3 幕 512~636），
  不是等比折减——旧口径 0.85 / 1.0 会让第 1 章达到 544，超出原生上限两倍以上。
- 伤害 / 格挡：第 1 章 ×0.9，第 2/3 章 ×1.0。
- 向下取整。

### 2.3 处决区间（基础 9）

| 玩家选择 | 共鸣 | 碎片 | 系数 | 伤害 |
| --- | --- | --- | --- | --- |
| 一只不清（抽到压制） | 5 | 3 | 12 | 108 |
| 一只不清（无压制） | 3 | 3 | 10 | 90 |
| 清 1 只（抽到压制） | 5 | 2 | 10 | 90 |
| 清 2 只（抽到压制） | 5 | 1 | 8 | 72 |
| 清 3 只（抽到压制） | 5 | 0 | 6 | 54 |
| 清 3 只（无压制） | 3 | 0 | 4 | 36 |

> **调参不变量**：每清一只碎片 = 少挨 `2 × 基础值`，应与碎片 HP（18）同量级 ⇒ 基础值 ≈ 9。
> 改基础值必须同步改碎片 HP，否则「清场 vs 抢血」会退化成单边最优。

## 4. 图鉴

`CznMonsterBestiaryPatch` 在「CZN 怪物」区块里给阿涅丝组登记 **3 条**：

| 条目 | 模型 | 招式按钮 |
| --- | --- | --- |
| 阿涅丝 | `Agnes`（Form A 骨架 `agnes.tscn`） | 共鸣连击 / 同调增幅 / 重锤 / 压制低语 + 受伤（通用撞击音，无怪叫）+ 死亡（`normal_groggy`，无采样） |
| 阿涅丝·弗布尔加扎伊特 | `AgnesFinal`（展示模型，骨架 `agnes_final.tscn`） | 崩坏重击 / 三裂闪击 / 压制咒波 / 万花斩 / 处决 + 受伤（通用撞击音，无怪叫）+ 死亡（`stance1_death` + `death` 采样） |
| 余响碎片 | `AgnesEcho` | 受伤（通用撞击音）/ 死亡（都落 `normal_hit`，无采样） |

- **第二形态必须是独立模型**：战斗里第二形态靠运行时换骨，同一个 `entry` 在图鉴只能看到 Form A。`AgnesFinal` 不参与任何战斗（`ShouldShowInCompendium = false`、不进 `AllPossibleMonsters`），只被补丁手动加为条目。
- **解锁联动**：本体已收录时，补丁把 `AGNES_FINAL` 的 id 并入本帧的「已收录」集合，条目不会显示成 `???`（只改开图鉴时临时建的 HashSet，不写存档）。
- **按钮是纯演出**：`Content/Bestiary/CznBestiaryMoves.cs` 组装 `BestiaryMonsterMove.FromAction`，直接对 Spine 播 clip + 播一条采样，不走 `PerformMove()`（图鉴里是 `NullCombatState`，跑战斗逻辑无意义且易抛异常）；非死亡动作播完接回各自待机，死亡动作停在末帧。

## 6. 注册与补丁

- 模型全部由 `ModelDb.Init()` 扫描自动注册（`Agnes` / `AgnesEcho` / `AgnesFinal` / `AgnesBoss` / `AgnesResonancePower` / `AgnesExecuteIntent` 内联于招式）。
- 遭遇注册：`MonsterContent.BossCatalog` 追加 `ModelDb.Encounter<AgnesBoss>()`；首领入池 / 指定章节由 `MonsterPoolPatch`（随机）+ `BossPlacementPatch`（指定）处理。
- 本组相关补丁：`CznMonsterBestiaryPatch`（图鉴区块）、`CznMonsterPlaySfxPatch` / `CznMonsterDeathSfxPatch`（采样接管）、`EchoDeathAnimPatch`（碎片死亡压缩）。
- 所有补丁限定本 mod 命名空间 + `instance is <本角色>` 判断，禁止整程序集 `PatchAll`；不引入 BaseLib / RitsuLib。
