## 1. 机制设计

### 1.1 CZN 原始阶段机（考证摘要）

- 刻度条件单元：`cdm_01_cu_0024/0028/0034/0038`、`cdp_turn_later_02`、`cdp_half_dead`（半血节点）
- 语义未 100% 破译（cs 表文本未提取），阶段映射按以下等价关系理解：

### 1.2 STS2 适配设计（本 mod 的设计裁定）

- **单实体双形态**：CZN 用 NAME_CHANGE + 模型切换保持 HP 连续。STS2 侧做单个 `MonsterModel` 子类，动作触发器指向 3000503 骨架（§3.1）；HP 不分段。若单实体方案受阻（§7 R1），降级为双实体方案（变身 = Form A 消亡 → Form B 上场并继承 HP 值），数值不变。
- **变身触发**：CZN 原条件半破译（`cdp_half_dead` + 计数清零）。采用简化裁定：**首次 HP < 50% 或第 4 回合（先到先得）进入变身回合**，此后每 N 回合（N=6，【设计值】）可再触发一次 pt4 型「再变身」：仅重置计数 + 召唤重铺，不再换背景（第二次变身 CZN 也切背景——是否同步待定）。
- **「共鸣」计数（cs02_2105/2088 适配）**：进场获得 5 层【设计值】；核心攻击的命中数/强化倍率 = 1 + 共鸣层数；变身回合清零并重铺召唤、回满共鸣至 3（第二形态数值更高但层数低，贴近 mode 形态 9→ 清 0 后循环）。
  - 层的增长源（贴 CZN：`3000541_10_pt1_00` 设 cs02_2089=8）：召唤物死亡时 Boss 获得对应层数（1 只 = 1 层，【设计值】），即「献祭宠物滋敌」节奏。
- **召唤**：变身回合终了 → 清空后召唤 **3000541 ×3**（3 个召唤位）。与波勒米卡「处决重召」同型，但触发源是**变身回合**而非仪式阈值。
- **N_DBF_CS（`cs00_0001/0003` +3/+5）**：具体 buff 语义待 cs 表补查；按「给全体己方加固定增益、给玩家上一层通用减益」的占位理解映射（§2.2 标注待定项）。
- **压力（STRESS_ADD 4/5/10，多带 `[fix]`）**：STS2 无压力机制 → 不还原原始值，折算进伤害/减益强度（单项 ≤10 压力在 CZN 属中低威胁）。
- **不还原项**：story pt4 的 KILL 处决演出（超出 Boss 正常行为边界，与波勒米卡裁定一致）；cut-in 系统演出（`disaster_s04_boss2_1/2`，cs02_2110/2111，无可提取逐帧素材）。

### 1.3 召唤物 3000541

- CZN 定义：三个实例 `_01/_10/_11` 的 HP 档位 46~49% / 60~63% / 60~63%（`stat_max_hp_pct`，GRADE_MULTI_HP / RANK_S），怪物本体 `link_monster_pattern_set` 存在（`3000541_01_ps` 等），但**骨架只有 2 个动作**（`normal_idle` 8.0s / `normal_hit` 8.0s）且 model_setting 动画表仅 `animation/hit`——**是纯展示/献祭型单位，无攻击行为**。
- STS2 设计：召唤物定义为**非攻击共鸣体**——在场时给 Boss 提供 §1.2 的层数联动；被击杀触发 Boss 强化。HP 极低（H12 ×3，【设计值】，CZN 档位按 46%~63% 中位折算后仍远低于 Boss）。
- 各实例差异（_01 vs _10/_11）在 STS2 合并为 1 种（位次差异对玩家不可见的概率型权重差异，无还原价值）。

### 1.4 状态机（提案：5 个 MoveState）

```
Enter→ 集结期（pt1: 连击/增益循环，共鸣 5 层起步）
 → 变身·壹（hp<50% 或第4回合：transform 动画链 + 更名 + 召唤×3 + 共鸣清零重铺）
 → 绽放期（pt2/pt3: 重击 + 压制、三连 + 斩击双威胁）
 → 变身·贰（每 6 回合：重召 ×3 + 共鸣重铺，不再入场演出）
 → 循环至死亡
死亡演出：Form A 无专用死亡动作（3000504 无 death/fatal）→ 用 Form B `stance1_fatal`(0.97s)/`stance1_death`(2.67s) 兜底
```
